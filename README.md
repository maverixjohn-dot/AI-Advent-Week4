# MCP Pipeline — учебный проект (DeepSeek + Flet)

Автоматический пайплайн из трёх MCP-инструментов с оркестрацией через LLM:

```
Flet UI (web, 127.0.0.1:8550)
  → агентный цикл DeepSeek (function calling, модель deepseek-v4-pro)
    → MCP-сервер (FastMCP, stdio, subprocess)
       ├─ search(query)        — веб-поиск DuckDuckGo
       ├─ summarize(text)      — алгоритмическая выжимка (без LLM)
       └─ save_to_file(data)   — допись в results.json
```

Цепочку выполняет сама LLM: системный промпт предписывает порядок
`search → summarize → save_to_file`, данные между инструментами передаются
через контекст диалога (tool messages). Трасса каждого прогона пишется в
`logs.json` и видна на странице «Логи».

## Установка и запуск

```bash
pip install -r requirements.txt
# вставьте ключ в agent.py: os.environ.setdefault("DEEPSEEK_API_KEY", "sk-...")
python app.py
# открыть http://127.0.0.1:8550
```

## Файлы

| Файл | Назначение |
|---|---|
| `mcp_server.py` | MCP-сервер (FastMCP), 3 инструмента, транспорт stdio |
| `agent.py` | MCP-клиент, агентный цикл DeepSeek, запись logs.json |
| `app.py` | Flet UI: «Пайплайн» / «Администрирование» / «Логи» |
| `results.json` | данные пайплайна (создаётся инструментом save_to_file) |
| `logs.json` | телеметрия прогонов (создаётся оркестратором) |

## Проверка цепочки

1. Автоматичность: один запрос → три вызова инструментов без участия пользователя
   (последовательность видна в живом логе на странице «Пайплайн»).
2. Передача данных: в логе видно, что аргумент `text` вызова `summarize` содержит
   сниппеты из результата `search`, а `data` вызова `save_to_file` — результат
   `summarize`.
3. Персистентность: `results.json` содержит запись с timestamp, запросом,
   результатами поиска и выжимкой.

## Примечания

- `deepseek-v4-pro` — рабочее имя модели, но с 14.09.2026 запросы
  маршрутизируются на V4.1-Flash (V4-Pro выводится из эксплуатации до выхода
  V4.1-Pro). Имя вынесено в константу `MODEL_NAME` в `agent.py`.
- Ключ по ТЗ прошит в коде через `os.environ.setdefault`: переменная
  экспортируется программой, дальше читается из окружения. Для боя хардкод
  ключа — плохая практика.
